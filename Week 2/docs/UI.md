# UI (`desktop/`)

Окно 1200×800, две зоны (`desktop/src/main.kt: Root`):

- **Слева (340px, тёмная):** дерево + кнопка `+`.
  - ` general` → общие чаты (`☰`-строки) + general `.md` (`M↓ title.md` + чекбокс active).
  - `▾ 📁 <проект>` → project `.md` + чаты проекта → `▾ 📁 <задача>` → task `.md` + чаты задачи.
  - Клик по чату → справа чат; клик по `.md` → справа viewer.
  - Чекбокс включает/выключает инжект дока (`toggleDocActive`).
- **Справа:** чат **или** viewer памяти (`Selection.ChatSel` / `Selection.DocSel`,
  `desktop/src/ui/AppViewModel.kt`).

## Чат (`ChatPane`)

- Шапка: имя чата + `▼/▲ prompt` (collapse/extend собранного system prompt,
  `AppViewModel.systemPrompt`, обновляется при каждом `ask` и смене выбора) +
  `очистить` (только историю). Под промптом: `~N tok (оценка) · last prompt_tokens=M`.
- Лента: `user` (голубой) / `assistant` (серый), текст в `SelectionContainer`.
  У каждого сообщения `⋯` → `Сохранить в память` (`startSave` с `chat.scope/parentId`).
- Ввод: поле + `➤`, `busy`-блок, ошибки — красной строкой под панелью.

## Viewer памяти (`MemoryPane`)

Title, `scope parentId · active/выключен`, кнопки `включить/выключить`, `удалить`,
текст `.md` как есть (read-only + выделение).

## Диалог создания (`CreateDialog`, кнопка `+`)

Тип (`CreateKind`): `Общий чат` (имя) / `Проект` (имя; сразу создаётся первый
чат проекта) / `Чат в проекте` (имя + проект) / `Задача` (имя + проект; сразу
создаётся первый чат задачи) / `Чат в задаче` (имя + задача).
После создания — автовыбор нового чата.

## Диалог сохранения (`SaveDialogView`)

Сырец (первые 300 симв) → варианты дистилляции (клик подставляет в поле) →
редактируемое поле факта → scope (`GENERAL/PROJECT/TASK`, дефолт = scope чата) →
родитель (проект/задача, если не GENERAL) → существующий `.md` **или** ☑ новый
документ + title. `Сохранить` активна только при заполненных факте, родителе и доке.

## Сценарий демо для видео (День 11)

1. Создать проект + задачу + чат; спросить без памяти (доки пустые).
2. Ответить что-то про стек/цель → `⋯ → Сохранить` → проверить текст в viewer.
3. Открыть `▼ prompt` — факт виден в system; задать вопрос повторно — ответ
   учитывает память. Выключить док чекбоксом — ответ «забывает».
4. Показать: история режется окном N=12 (длинный диалог), факты переживают обрезку.
